# Cyber Drill Dark Web Investigation 

Repositori ini berisi kumpulan file dan dokumen investigasi digital yang digunakan dalam pelatihan _cyber drill_ investigasi _dark web_.
File di dalam repo ini ditujukan untuk mendukung praktik _hands-on training_ dalam memahami teknik eksplorasi dan investigasi di _dark web_ dengan aman.

## Cara Mengunduh & Menggunakan

### Opsi 1 - Clone dengan Git
#### Jika belum memiliki git di perangkat, lakukan instalasi terlebih dahulu.
- Windows:
  download git (https://git-scm.com/downloads/win)

- Kali Linux:
  ```bash
  sudo apt install git -y
  ```
- macOS: 
  ```bash
  brew install git (butuh HomeBrew) atau Git via Xcode Tools
  ```
#### Clone Repositori & Masuk ke Direktori File.
Buka terminal atau Git Bash, lalu jalankan:
```bash
git clone https://github.com/khalsum/CyberDrillDW.git
cd B02
```
